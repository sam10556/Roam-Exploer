# Roam-Explorer 🌍✈️

**Roam-Explorer** is a modern travel blog website built using only **HTML**, **CSS**, and **vanilla JavaScript**. The site features a **parallax scrolling effect** to enhance the storytelling experience with immersive visuals and interactive content.

---

## ✨ Features

- 🌄 **Parallax Scrolling** — Smooth, eye-catching scroll effects for an immersive travel experience.
- 📸 **Image-Centric Design** — Stunning full-width travel imagery with layered effects.
- 🧭 **Lightweight** — No frameworks, just pure HTML, CSS, and JavaScript.
- 🗺️ **Responsive Layout** — Optimized for all screen sizes: desktop, tablet, and mobile.
- 💬 **Engaging Blog Sections** — Highlight destinations, travel tips, and personal stories.
